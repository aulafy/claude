# Match a model to your hardware

A local model is a trade-off between capability, memory, speed and context. Start with the smallest model that can plausibly solve your task. Leave headroom for the operating system and the application around it.

## Practice

Record your operating system, available RAM or unified memory, GPU memory if present and free disk space. Pick one small instruct model and note its size before downloading it. If the model barely fits, choose a smaller quantization or a smaller model.

## Evidence

Keep a short hardware note with the model name, approximate size and reason for choosing it. Treat model pages and release notes as the source of truth for current tags and requirements.
