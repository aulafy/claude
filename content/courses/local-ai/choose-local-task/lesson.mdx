# Choose one useful local task

Do not begin by downloading the largest model your computer can run. Choose one task that is useful, low risk and easy to repeat: classify notes, rewrite a draft, extract fields from a sample document or explain a small code file.

Write three lines before opening a model:

1. **Input:** what information will the model receive?
2. **Output:** what format should it return?
3. **Check:** how will you decide whether the result is good enough?

## Practice

Use a non-sensitive sample and run the task twice. Keep the prompt, input size and expected format unchanged. Record one success and one failure.

## Evidence

Save the task, the acceptance check and the limitation you found. Never use real private data for this first experiment.
