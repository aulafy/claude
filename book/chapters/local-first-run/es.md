## Antes de empezar

Instalar un modelo local tiene tres momentos distintos: preparar el programa, conseguir que responda y comprobar si sirve para tu tarea. No confundas el primer «hola» con una evaluación completa. En esta práctica usarás un texto ficticio y una carpeta de prueba.

## 1. Prepara una instalación reversible

Antes de descargar nada, anota el programa, la versión, el origen del instalador, el espacio que ocupará y dónde se guardarán sus archivos. Lee la documentación oficial de la herramienta elegida. No ejecutes un script que no entiendas ni concedas permisos de administrador por costumbre.

Usa una carpeta de prueba separada de tus documentos personales. Si la instalación ofrece opciones de red, telemetría o acceso a carpetas, léelas antes de aceptar. No pongas claves ni datos privados en una configuración de ejemplo.

## 2. Comprueba que arranca

Tras instalar, haz la prueba mínima:

```text
Entrada: escribe tres frases sobre una biblioteca ficticia.
Límite: no uses datos fuera de esta petición.
Resultado esperado: una respuesta breve que conserve los tres hechos.
Registro: versión, tiempo aproximado y errores visibles.
```

Que aparezca una respuesta demuestra que el programa puede iniciar una sesión. No demuestra todavía que conserve los hechos, que sea rápido o que sea adecuado para un documento real.

## 3. Comprueba la tarea

Repite el caso con un texto de referencia y una tabla de comprobación. Marca si la respuesta conserva cada hecho, añade información, se niega a responder o se queda sin recursos. Guarda el resultado de la prueba, no una promesa sobre lo que debería hacer.

Si algo falla, reduce el tamaño de la entrada y repite una sola variable cada vez. Una respuesta lenta puede ser aceptable para estudiar y no para atención al cliente. Una respuesta fluida puede seguir siendo incorrecta.

## 4. Limpia y decide

Elimina la carpeta de prueba solo después de confirmar qué archivos contiene y de que no necesitas el registro. Conserva la versión y los límites observados si vas a repetir la instalación. Si no puedes explicar dónde quedan los datos o qué conexiones existen, detén el uso con información real y pide revisión técnica.

## Tu resultado

Has terminado cuando distingues instalación correcta, ejecución correcta y resultado útil, y tienes una prueba que puedes repetir o borrar. La IA local puede ofrecer más control, pero exige mantener el sistema, proteger archivos y comprobar cada actualización.

En el siguiente capítulo medirás contexto, memoria y velocidad sin convertir una cifra anunciada en una garantía.
