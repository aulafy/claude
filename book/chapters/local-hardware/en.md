## Before you start

The question “which model can I install?” starts with another: “what resources does my computer have, and what task do I want to test?” Execution memory, free storage, temperature and speed matter more than a list of names.

## 1. Describe your task

Choose one small, concrete task, such as summarizing a 500-word fictional text without sending it to any service. Note how long you would spend checking it and which error you would not accept. A task without a criterion cannot tell you whether the computer is sufficient.

## 2. Measure resources

Make a record without sharing it outside your computer:

```text
Operating system and version:
Total and available memory:
Graphics or unified memory, if relevant:
Free storage:
Temperature or noise during a normal task:
Response time for a small test:
```

Available memory changes when you close an application, so note when you measured it. The size of a downloaded file is not the memory the process will need while answering.

## 3. Start with the smallest test

Do not download the largest model you can find first. Choose a test you can delete and repeat: fictional text, one response and a time limit. Observe whether the computer responds, the application closes and the result is useful enough for your task.

Also record what you do not know. A number announced by a tool may refer to another version, format or operating system. Check the documentation for the program you will actually use before relying on it.

## 4. Decide with headroom

If a test consumes all resources, do not make it your daily configuration. Leave room for the system, your files and clean recovery. Do not disable protections or delete personal data to save a few seconds.

Local installation can improve data control, but it does not remove every risk: the computer, files, network and application still need protection. Document what is downloaded and where it is stored.

## Your result

You are done when you have a task, resource record, small test, observed result and reasoned decision. The best choice is the one you can run, review and recover on your real computer.
