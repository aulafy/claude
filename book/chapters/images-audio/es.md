## Antes de empezar

Vas a preparar una pieza multimedia ficticia, pero no vas a publicarla. El resultado de una herramienta no elimina las decisiones humanas sobre encargo, referencias, consentimiento, privacidad y licencia.

Para practicar, imagina un cartel para una biblioteca de barrio. No uses fotografías de personas reales ni voces reconocibles.

## 1. Escribe el encargo

Anota el propósito, el público, el formato y los elementos que sí deben aparecer. Por ejemplo: “Cartel vertical para anunciar una tarde de lectura infantil. Debe ser claro, amable y dejar un espacio para fecha y lugar”.

También anota lo que no debe aparecer: nombres de menores, caras identificables, teléfonos reales, logotipos ajenos o afirmaciones que no estén confirmadas.

## 2. Separa las referencias

Una referencia puede ser una imagen, un audio, una paleta, una descripción o una obra que has encontrado. Registra de dónde procede y qué permiso tienes para usarla. “Está en internet” no significa “se puede reutilizar”.

Si no puedes justificar la licencia, sustitúyela por una descripción propia o por un recurso con permiso claro. Conserva esa decisión junto al proyecto.

## 3. Genera una primera versión

Pide una composición, no una copia de una obra concreta. Incluye el formato y las restricciones del encargo. Si la herramienta guarda el prompt o la configuración, archívalos con la fecha y el identificador de la versión.

Para audio, añade el idioma, la duración aproximada y el tono. No uses una voz de una persona real como referencia sin consentimiento explícito y un uso permitido.

## 4. Revisa antes de compartir

Comprueba cuatro capas:

1. **Contenido**: ¿comunica el encargo y evita datos inventados?
2. **Personas**: ¿aparece alguien identificable o imitado sin permiso?
3. **Materiales**: ¿puedes explicar la licencia de cada referencia?
4. **Accesibilidad**: ¿el texto se lee, el contraste funciona y el audio tiene transcripción o alternativa?

Anota los problemas y conserva la versión revisada. No presentes una pieza generada como si fuera una fotografía documental.

## 5. Reconoce el fallo típico

Una imagen puede introducir texto ilegible, manos deformadas, símbolos parecidos a marcas o una escena que parece real aunque sea inventada. Un audio puede pronunciar mal un nombre o atribuir una frase a una persona.

Si el error cambia el significado, detén la publicación. Recorta, regenera o cambia de técnica. Cuando el contexto importe, etiqueta claramente la pieza como generada o compuesta.

## Tu resultado

Has preparado una ficha mínima de uso: encargo, referencias, permisos, configuración, revisión y alternativa accesible. Esa ficha permite corregir la pieza y responder preguntas sin depender de la memoria.
