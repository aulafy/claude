## Before you start

A “best tools” list does not tell you which tool fits your task. In this practice you will compare two fictional assistants using exactly the same request. You do not need accounts or real data.

## 1. Fix a task and a sample

Use this fictional text:

```text
The book club meets on Thursday at 6:00 p.m. in room 1.
The session lasts 30 minutes. Each person may bring one book.
The text does not state a price, number of places or registration method.
```

The task is: “write a three-sentence notice, do not invent facts and do not send it”. Do not change the request between tools. If you change the sample or instructions, you are no longer comparing equivalent results.

## 2. Define criteria before looking at results

Give each tool a score and an observation, not just an impression:

| Criterion | Question |
| --- | --- |
| Faithfulness | Does it keep the day, time, place and duration without adding facts? |
| Usefulness | Is the notice clear and three sentences long? |
| Correction | Can you spot and fix a mistake? |
| Data | What information would leave the device? |
| Cost and access | Does it require an account, payment or a particular connection? |

The last two criteria can decide the choice even if one tool writes more elegantly. Cost also includes the time needed to review, configure and recover from a failure.

## 3. Run the same test

You can make a table like this with two fictional assistants, “A” and “B”:

| Tool | Faithfulness /5 | Usefulness /5 | Data and cost | Observation |
| --- | ---: | ---: | --- | --- |
| A | 5 | 3 | Not stated | Asks about the price instead of inventing it |
| B | 2 | 5 | Sends text to an external service | Adds places and a registration date |

The scores are not mathematical truth. They make your reason for choosing visible. Also keep the original text, request, date and tool version if one exists.

## 4. Repeat the difficult case

Add a second test: request the same notice, but include “if a detail is missing, label it as pending”. Check whether the tool follows this, keeps the four known details and leaves out price, places and registration.

If a tool fails, do not reject it from one case or hide the failure because its writing is attractive. Repeat with two or three small samples. If you plan to use sensitive data, stop and check your organization’s rules before sending it.

## Your result

Your comparison is useful when another person can repeat the task, see the same sample, read your criteria and understand the limitations. The winning tool is not the one with the highest isolated score: it is the one that fits the risk, data, cost and result you need.
