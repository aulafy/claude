# Inbox del generador de tutoriales

Coloca aqui senales en Markdown o texto plano: posts de X resumidos por Grok, repos de GitHub, cambios de documentacion oficial, ideas de alumnos o resultados de Hugging Face.

El generador local lee el archivo mas reciente si no pasas `--input`.

Ejemplo:

```markdown
# Senales X - Claude Code y Codex

- Post: https://x.com/i/status/...
- Tema: plugin que conecta Codex dentro de Claude Code
- Fuente primaria pendiente: repo GitHub del plugin
- Riesgo: puede ser hype si no hay instalacion reproducible
- Tutorial posible: "Claude + Codex juntos en un solo flujo"
```
